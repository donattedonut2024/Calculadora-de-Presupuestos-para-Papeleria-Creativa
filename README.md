## ✨ Descripción

**Calculadora Donatte** es una aplicación web progresiva (PWA) diseñada para emprendedores de papelería creativa. Permite calcular costos de producción, márgenes de ganancia y precios de venta de manera rápida, eliminando las cuentas manuales y el desorden.

La app está personalizada con la identidad visual de la marca **Donatte Donut** (colores pastel, tipografías redondeadas y diseño amigable).

## 🚀 Funcionalidades Principales

### 1. 📝 Presupuestador Inteligente
* Cálculo automático de **Materiales + Mano de Obra + Diseño**.
* Ajuste de porcentaje de **Rentabilidad** deseada.
* Visualización clara de costos reales vs. ganancia neta.
* **Limpieza de decimales:** Muestra precios redondos (ej: `$2500`) para una lectura más limpia.

### 2. 🧮 Calculadora Auxiliar (Panel Lateral)
* Permite sacar **Costos Unitarios** rápidamente sin salir del presupuesto principal.
* *Ejemplo:* Si una resma cuesta $12.000 y trae 500 hojas, calcula cuánto cuestan las 8 hojas que usaste para el pedido.

### 3. 📸 Generador de Tickets (Doble Descarga)
Gracias a la integración con `html2canvas`, la app genera imágenes PNG listas para compartir:
* **📄 Ticket Cliente:** Un diseño limpio y estético con el logo de la marca y el precio final (sin revelar costos internos). Ideal para enviar por WhatsApp.
* **📋 Ticket Interno:** Una ficha técnica detallada para el emprendedor con el desglose de materiales, gastos y ganancia real.

### 4. 📂 Historial Local
* Guarda automáticamente los últimos pedidos en la memoria del navegador (`LocalStorage`).
* Permite revisar presupuestos anteriores y ver el detalle de materiales usados.

## 🎨 Tecnologías Usadas

* **HTML5 & CSS3:** Diseño responsivo y estilización con variables CSS (Paleta Donatte).
* **JavaScript (Vanilla):** Lógica de cálculo y manipulación del DOM.
* **Local Storage:** Persistencia de datos en el dispositivo.
* **html2canvas:** Librería externa para renderizar los tickets como imágenes descargables.
* **Google Fonts:** Tipografía 'Poppins' para mantener la identidad de marca.

## 📱 Cómo instalar en el celular

No necesitas descargar nada del App Store.
1.  Abre el enlace de la app en **Chrome** (Android) o **Safari** (iPhone).
2.  Abre el menú de opciones.
3.  Selecciona **"Agregar a la pantalla de inicio"**.
4.  ¡Listo! Aparecerá como una app nativa con el icono de Donatte.
